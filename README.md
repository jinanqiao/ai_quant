## ⚠️ 版本说明（重要）

课程各章节对应的源码版本有所不同。如需进行源码学习或完成作业，请务必根据课程要求下载对应的版本。

#### 1. deltafq (量化框架)
1. 进入 PyPI 库托管平台：https://pypi.org/project/deltafq/
2. 点击 `Release History`。
3. 选择对应版本页面（例如 0.5.0 版本：https://pypi.org/project/deltafq/0.5.0/ ）。
4. 点击 `Download Files` 获取源码。

`提示`：在 PyPI 链接后缀直接加上版本号即可快速访问对应页面。

#### 2. deltafstation (量化平台)
1. 进入 GitHub Releases 页面：https://github.com/Delta-F/deltafstation/releases
2. 选择课节对应的版本，如 0.6.6：https://github.com/Delta-F/deltafstation/releases/tag/v0.6.6
3. 点击最下方的 `Assets` 下载对应的 zip 文件

如有更多问题，请至问答区提问即可。
